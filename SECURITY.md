# Security Policy

## Supported Versions

We actively support and release security patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in `cv-benchkit`, please do **NOT** open a public issue.

Instead, please report vulnerabilities via **GitHub Private Vulnerability Reporting**:
1. Navigate to the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Provide details regarding the potential impact, reproduction steps, and any proof-of-concept code.

Alternatively, you can contact the maintainer directly at `rajuday6002@gmail.com` with the subject `[SECURITY] cv-benchkit Vulnerability Report`.

We will acknowledge receipt within 48 hours and work with you to coordinate a responsible public disclosure and release.
